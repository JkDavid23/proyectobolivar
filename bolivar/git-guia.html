Guía Completa de Git

Comandos esenciales para el control de versiones

Configuración Inicial

git config --global user.name "Tu Nombre"

Configura tu nombre de usuario

git config --global user.email "tu@email.com"

Configura tu email

Crear Repositorios

git init

Inicializa un nuevo repositorio Git

git clone [url]

Clona un repositorio existente

Trabajo Diario

git status

Muestra el estado de tus archivos

git add [archivo]

Añade un archivo al área de staging

git commit -m "Mensaje"

Guarda los cambios en el repositorio

git push [remote] [rama]

Envía tus commits al repositorio remoto

Ramas

git branch

Lista todas las ramas

git branch [nombre-rama]

Crea una nueva rama

git checkout [nombre-rama]

Cambia a otra rama

git merge [rama]

Fusiona una rama con la actual

Actualizar y Publicar

git remote add [remote] [url]

Añade un repositorio remoto

git fetch [remote]

Descarga cambios del remoto

git pull [remote] [rama]

Obtiene cambios y fusiona con la rama actual

Historial

git log

Muestra el historial de commits

git log --oneline

Historial de commits en una línea

git diff

Muestra cambios no preparados

Deshacer Cambios

git restore [archivo]

Descarta cambios en el directorio de trabajo

git reset [commit]

Deshace commits manteniendo los cambios

git revert [commit]

Crea un nuevo commit que deshace cambios anteriores
